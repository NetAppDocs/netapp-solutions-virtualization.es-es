= Herramientas de integración de ONTAP para datastores NFS en entornos VMware
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Obtén información sobre las herramientas de integración de ONTAP para gestionar, supervisar y proteger almacenes de datos NFS en entornos de VMware, incluidas ONTAP tools for VMware vSphere, el plugin NFS VAAI y SnapCenter Plug-in for VMware vSphere.

NetApp ofrece las siguientes herramientas para gestionar y proteger los almacenes de datos NFS en entornos VMware:

* *link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/index.html["ONTAP tools for VMware vSphere"^]*: integra la gestión de ONTAP en vSphere Client para el aprovisionamiento, la supervisión y la gestión de almacenes de datos NFS, y aplica la configuración recomendada para los hosts ESXi.
* *link:https://docs.netapp.com/us-en/nfs-plugin-vmware-vaai/index.html["Complemento NFS de NetApp para VMware VAAI"^]*: delega operaciones de almacenamiento, como la clonación, a ONTAP, lo que mejora el rendimiento y reduce la carga en los hosts ESXi.
* *link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/protect/enable-storage-replication-adapter.html["Adaptador de replicación de almacenamiento (SRA)"^]*: se integra con VMware Live Site Recovery (anteriormente VMware Site Recovery Manager) para coordinar la recuperación ante desastres mediante la replicación de ONTAP SnapMirror.
* *link:vmw-dr-gs.html["NetApp Disaster Recovery"]*: Orquesta la recuperación ante desastres de las VM en almacenes de datos NFS desde la NetApp Console.
* *link:https://docs.netapp.com/us-en/sc-plugin-vmware-vsphere/index.html["Plugin de SnapCenter para VMware vSphere"^]*: proporciona copia de seguridad y restauración coherentes ante fallos y coherentes con la VM para las VM en almacenes de datos NFS.
* *link:https://docs.netapp.com/us-en/data-infrastructure-insights/index.html["Data Infrastructure Insights de NetApp"^]*: proporciona visibilidad sobre el rendimiento y el estado del almacenamiento ONTAP y la infraestructura de VMware.


Estas herramientas agilizan las operaciones, mejoran el rendimiento y proporcionan protección de datos para los datastores NFS en entornos VMware.
