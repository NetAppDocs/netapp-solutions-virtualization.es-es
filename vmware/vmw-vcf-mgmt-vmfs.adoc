= Flujo de trabajo de implementación para la convergencia de instancias del servidor vCenter al dominio de gestión de VCF con almacenes de datos VMFS
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Integra un clúster existente de vSphere con almacenes de datos VMFS de ONTAP de NetApp en un dominio de gestión de VMware Cloud Foundation. Vas a revisar los requisitos de configuración, implementar las ONTAP tools y aprovisionar almacenes de datos VMFS, y usar la herramienta VCF Installer para validar y usar tus componentes existentes, implementar los nuevos componentes necesarios y configurar la plataforma.

Este flujo de trabajo también se utiliza para emplear cualquier almacén de datos VMFS compatible como almacenamiento principal para el dominio de gestión de VCF.

Para obtener una visión general del proceso de conversión, consulta la documentación de VMware: https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["Convertir la infraestructura virtual existente en un VCF"].
