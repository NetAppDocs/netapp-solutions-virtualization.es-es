= Crear SVM y LIF para los almacenes de datos NFS vVols en un dominio de carga de trabajo de VCF
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Crea una máquina virtual de almacenamiento (SVM) y varias interfaces lógicas (LIF) en un sistema ONTAP para soportar el tráfico NFS de los almacenes de datos vVols en un dominio de cargas de trabajo de VMware Cloud Foundation.

Para agregar nuevos LIF a un SVM existente, consulte la documentación de ONTAP :link:https://docs.netapp.com/us-en/ontap/networking/create_a_lif.html["Crear LIF de ONTAP"^] .

.Pasos
. En el Administrador del sistema ONTAP , navegue hasta *Máquinas virtuales de almacenamiento* en el menú de la izquierda y haga clic en *+ Agregar* para comenzar.
+
.Mostrar ejemplo
[%collapsible]
====
image:vmware-vcf-asa-001.png["Haga clic en Agregar para comenzar a crear SVM"]

====
. En el asistente *Agregar VM de almacenamiento*, proporcione un *Nombre* para la SVM, seleccione el *Espacio IP* y luego, en *Protocolo de acceso*, haga clic en la pestaña *SMB/CIFS, NFS, S3* y marque la casilla para *Habilitar NFS*.
+
.Mostrar ejemplo
[%collapsible]
====
image:vmware-vcf-aff-035.png["Asistente para agregar máquinas virtuales de almacenamiento: habilitar NFS"]

====
+

TIP: No necesitas marcar la casilla *Permitir acceso de cliente de NFS*. ONTAP tools for VMware vSphere se usarán para automatizar el proceso de implementación del datastore, lo que incluye proporcionar acceso de cliente para los hosts vSphere.

. En la sección *Interfaz de red*, complete la *Dirección IP*, la *Máscara de subred* y el *Dominio de transmisión y puerto* para el primer LIF.  Para los LIF posteriores, puede utilizar configuraciones individuales o activar la casilla de verificación para utilizar configuraciones comunes en todos los LIF restantes.
+
.Mostrar ejemplo
[%collapsible]
====
image:vmware-vcf-aff-036.png["Complete la información de la red para LIF"]

====
. Elija si desea habilitar la cuenta de administración de VM de almacenamiento (para entornos de múltiples inquilinos) y haga clic en *Guardar* para crear la SVM.
+
.Mostrar ejemplo
[%collapsible]
====
image:vmware-vcf-asa-004.png["Habilitar cuenta SVM y Finalizar"]

====
