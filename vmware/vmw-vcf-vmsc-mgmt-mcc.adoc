[role="lead"]
En este caso de uso describimos el procedimiento para configurar un clúster stretch para el dominio de gestión de VMware Cloud Foundation (VCF) utilizando ONTAP MetroCluster con FC, iSCSI, NVMe-oF, NFSv3 o NFSv4.1 como almacén de datos principal. VCF ofrece flexibilidad en las opciones de implementación según tus necesidades. La herramienta VCF Installer se utiliza para implementar un nuevo dominio de gestión de VCF o convertir un entorno existente de vSphere en un dominio de gestión de VCF. En este documento, nos centraremos en la parte de MetroCluster y te indicaremos otra documentación según los pasos de implementación.

image:vmw-vcf-vmsc-mgmt-mcc-001.png["Dominio de administración de VCF con vMSC, ancho=500"]



[[introduction]]
== Introducción

En esta solución vamos a mostrar cómo implementar un dominio de gestión VCF ampliado con ONTAP MetroCluster como almacén de datos principal. MetroCluster permite implementar una solución de alta disponibilidad para todas las cargas de trabajo que se ejecutan en el clúster de ONTAP. Si necesitas implementar una solución de alta disponibilidad específica para cargas de trabajo, considera usar SnapMirror active sync (SAN y NAS). SnapMirror active sync (SAN) funciona a nivel de grupo de consistencia, mientras que SnapMirror active sync (NAS) funciona a nivel de SVM. Para más información, consulta link:vmw-vcf-vmsc-mgmt-smas.html["Configura un clúster extendido para un dominio de gestión VCF usando SnapMirror Active Sync (SAN y NAS)"].



[[prerequisites]]
== Prerrequisitos

Este escenario requiere los siguientes componentes y configuraciones:

* Configuración de ONTAP MetroCluster compatible
* Máquina virtual de almacenamiento (SVM) configurada con el protocolo de almacenamiento preferido.
* Se ha creado una interfaz lógica (LIF) para transportar tráfico de almacenamiento y está asociada a la SVM.

[[deployment-steps-for-greenfield-vcf-management-domain-with-metrocluster]]
== Pasos para la implementación de un dominio de gestión de VCF de nueva creación con MetroCluster

Para una implementación Greenfield (una nueva implementación sin ningún componente VCF preexistente), se utiliza la herramienta VCF Installer para implementar el dominio de gestión. VMFS sobre FC y NFSv3 son compatibles en este escenario.

En el caso de VMFS en FC, consulta link:vmw-vcf-mgmt-principal-fc.html["Dominio de gestión VCF con un almacén de datos VMFS basado en FC en ONTAP como almacenamiento principal"] para más información. Para NFSv3, consulta link:vmw-vcf-mgmt-principal-nfs.html["Dominio de gestión VCF con un datastore NFSv3 en ONTAP como almacenamiento principal"] para más información.



[[deployment-steps-for-brownfield-vcf-management-domain-with-metrocluster]]
== Pasos para la implementación del dominio de gestión de VCF en un entorno ya existente con MetroCluster

Una implementación brownfield es un escenario en el que tienes un entorno existente de vSphere y quieres convergerlo como un dominio de gestión de VCF.

Para iSCSI, NVMe-oF y NFSv4.1, necesitas configurarlo con vCenter (preferiblemente con ONTAP tools) y luego usar la herramienta instaladora de VCF para convergerlo en el dominio de gestión. Para más información, consulta link:vmw-vcf-mgmt-vmfs.html["Convergencia de vCenter con el almacén de datos VMFS"] y link:vmw-vcf-mgmt-nfs.html["Convergencia de vCenter con el datastore NFS"].
