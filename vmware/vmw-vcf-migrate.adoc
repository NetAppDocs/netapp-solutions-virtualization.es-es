= Conoce cómo converger un entorno vSphere con los datastores existentes a un dominio de gestión de VCF
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Cualquier entorno de vSphere compatible puede integrarse en un entorno de nube privada de VCF. Puede converger en un dominio de gestión de VCF o importarse como dominio de carga de trabajo. Esta solución muestra cómo los almacenes de datos VMFS o NFS existentes en vSphere se convierten en el almacenamiento principal cuando el clúster se convierte en un dominio de gestión de VCF.



[[solution-overview]]
== Descripción general de la solución

Esta solución muestra cómo los almacenes de datos VMFS o NFS existentes en vSphere pasan a ser el almacenamiento principal cuando el clúster se integra en un dominio de gestión de VCF.

Este proceso se beneficia de la solidez y flexibilidad del almacenamiento ONTAP para garantizar un acceso y una gestión de datos sin interrupciones. Después de que se establece un dominio de gestión de VCF mediante el proceso de convergencia, los administradores pueden importar de forma eficiente entornos adicionales de vSphere, incluidos aquellos que utilizan tanto almacenes de datos VMFS como NFS, al ecosistema de VCF.

Esta integración no solo mejora el uso de recursos, sino que también simplifica la gestión de la infraestructura de nube privada, lo que garantiza una transición fluida con una interrupción mínima de las cargas de trabajo existentes.



[[architecture-overview]]
== Descripción general de la arquitectura

La arquitectura de las herramientas ONTAP se integra perfectamente con los entornos VMware, aprovechando un marco modular y escalable que incluye los servicios de las herramientas ONTAP , el complemento vSphere y las API REST para permitir una gestión eficiente del almacenamiento, la automatización y la protección de datos.

Las ONTAP tools for VMware vSphere se pueden instalar en configuraciones HA o no HA.
