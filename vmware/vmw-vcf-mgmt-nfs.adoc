= Flujo de trabajo de implementación para converger una instancia de servidor vCenter al dominio de gestión de VCF con almacenes de datos NFS
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Converge un clúster existente de vSphere con almacenes de datos NFS de NetApp ONTAP a un dominio de gestión de VMware Cloud Foundation. Vas a revisar los requisitos de configuración, implementar las ONTAP tools y aprovisionar almacenes de datos NFS, y usar la VCF Installer Tool para validar y usar tus componentes existentes, desplegar los nuevos componentes necesarios y configurar la plataforma.

Este flujo de trabajo también es aplicable si se van a utilizar almacenes de datos ONTAP NFS 4.1 como almacenamiento principal para el dominio de gestión de VCF.

Para obtener una visión general del proceso de convergencia, consulta la documentación de VMware: https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["Convertir la infraestructura virtual existente en un VCF"].
